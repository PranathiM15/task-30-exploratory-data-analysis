# Task 30 — Exploratory Data Analysis Web App

A notebook-free EDA workspace built with Python, Pandas, NumPy and Matplotlib. It runs locally in your browser and uses Python's built-in HTTP server; no Flask, Streamlit, Node.js or Jupyter Notebook is required.

## Included features

- Choose one of the three bundled datasets or upload your own CSV.
- Inspect dataset shape, numeric/categorical column counts, missing cells and duplicate rows.
- Review a schema / column quality table and descriptive statistics.
- View four Matplotlib charts: numeric distribution, missing values, category frequency and numeric relationships.
- Read five automatically generated observations and preview the first ten records.
- Clean the selected CSV by removing exact duplicate rows, trimming text values and filling missing numeric values with the median and missing categorical values with the mode. The original CSV is not overwritten; a cleaned copy is saved to `cleaned/` and downloaded. Pre-cleaned copies of all three bundled datasets are already included in that folder.

## Datasets included

| File | Rows | Columns | Dataset note |
|---|---:|---:|---|
| `iris.csv` | 150 | 5 | Classic Iris dataset, genuine bundled Iris records. |
| `titanic_sample_synthetic.csv` | 891 | 15 | Synthetic teaching sample with familiar Titanic-style fields. It is **not** the original passenger manifest / Kaggle dataset. |
| `student_performance_sample_synthetic.csv` | 395 | 33 | Synthetic teaching sample shaped around the UCI Student Performance field names. It is **not** the original student records. |

**Important data note:** The build environment could not retrieve the original Titanic and UCI Student Performance CSVs. Those two files are explicitly labeled synthetic so generated records are not mistaken for authentic source data. The Iris CSV is based on the classic Iris dataset. Replace the two sample CSVs with source data if your instructor specifically requires original records.

## Run on Windows (VS Code terminal)

1. Download and extract `Task30_EDA_WebApp.zip`.
2. Open the extracted `Task30_EDA_WebApp` folder in VS Code.
3. In VS Code, choose **Terminal → New Terminal**. Check that the terminal path ends with `Task30_EDA_WebApp`.
4. Install the required libraries:

   ```powershell
   py -m pip install -r requirements.txt
   ```

5. Start the app:

   ```powershell
   py app.py
   ```

6. Open this address in Chrome:

   `http://127.0.0.1:8000`

7. Choose Iris, Titanic sample or Student Performance sample from the dataset menu. Upload another CSV with **Upload CSV**. Use **Clean & export** to download a cleaned copy.
8. To stop the local server, return to the VS Code terminal and press `Ctrl + C`.

### If `py` is not recognized

Try these commands instead:

```powershell
python --version
python -m pip install -r requirements.txt
python app.py
```

### If port 8000 is already in use

Close the other local server or change `port=8000` near the bottom of `app.py` to `port=8001`, save, and run `py app.py` again. Open `http://127.0.0.1:8001`.

## Data/source notes

- Iris: Fisher's Iris dataset; UCI Machine Learning Repository, DOI `10.24432/C56C76` (CC BY 4.0). https://archive.ics.uci.edu/dataset/53/iris
- Student Performance field descriptions: UCI Machine Learning Repository, dataset 320. https://archive.ics.uci.edu/dataset/320/student+performance
- Titanic-style field reference used for sample schema: seaborn-data Titanic file. The rows in this project's Titanic CSV are synthetic, not copied from that file. https://github.com/mwaskom/seaborn-data/blob/master/titanic.csv

## Troubleshooting

- Make sure terminal's current directory is `Task30_EDA_WebApp` before running `py app.py`.
- Keep the terminal open while the web app is running.
- If a package is missing, rerun `py -m pip install -r requirements.txt`.
- Upload CSV files only (maximum upload size: 15 MB).
